# Community Wellness Activity Directory

## About the Project
The Community Wellness Activity Directory is a web-based platform designed to promote mental well-being by helping individuals discover wellness activities and resources available in their community.

The website aims to encourage people to participate in activities that support mental health, reduce stress, improve social connections, and develop a healthier lifestyle.

## Objectives
- Promote awareness about mental health and wellness.
- Help users discover community wellness activities.
- Encourage participation in social and recreational activities.
- Provide a simple and user-friendly browsing experience.
- Support healthier and more connected communities.

## Technologies Used
- **HTML5** – For creating the structure of the website.
- **CSS3** – For styling and designing the user interface.
- **JavaScript** – For adding interactivity and functionality.

## Key Features
- Clean and user-friendly interface.
- Information about community wellness activities.
- Easy navigation between different sections.
- Responsive and visually appealing design.
- Interactive elements using JavaScript.
